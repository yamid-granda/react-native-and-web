# todo

Proposals waiting to be implemented. `code-optimization-proposals` adds files
here; `code-optimization-proposals-implement` takes the **oldest** one.

Selection is lexicographic ascending by filename. Every filename starts with
`YYYY-MM-DD-HH-mm-ss-`, so that is chronological order — never sort by
modification time, because a checkout or a merge rewrites mtimes.

Lifecycle: `todo` → `in-progress` → `implemented`, with `rejected` as the
off-ramp.
